Left Ventricle

Pedoman Produksi

Aspek Medis

Semua label, deskripsi, urutan dan warna harus memiliki status review. Animasi tidak boleh dipresentasikan sebagai aliran fisiologis kuantitatif.

Aspek Informatika

Gunakan semantic node ID, modul Three.js terpisah, konten JSON berversi, logging anonim, dan acceptance test yang dapat direplikasi.

Aspek Penelitian

Preliminary study menilai kelengkapan artefak, fungsi, performa, kompatibilitas, dan revisi berbasis expert review, bukan efektivitas belajar.

Definition of Storyboard Ready

Storyboard siap digunakan sebagai dasar implementasi ketika struktur jantung MVP, istilah medis, urutan sirkulasi, target perangkat, dan format expert review telah disepakati. Setelah itu, setiap scene dapat langsung diturunkan menjadi issue atau user story pada backlog pengembangan.
